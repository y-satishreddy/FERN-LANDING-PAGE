# FERN-LANDING-PAGE

A modern, fully responsive real estate landing page built with HTML, CSS, JavaScript, Tailwind CSS, and AOS, featuring smooth animations, interactive sections, and form validation.

## 🌟 Features

- Clean and modern UI design
- Fully responsive layout
- Smooth scroll animations
- Interactive master plan with amenity hotspots
- Expandable connectivity accordion
- JavaScript form validation
- Enquiry and brochure popups
- Mobile-friendly design

## 🧰 Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- AOS (Animate On Scroll)
- Font Awesome

## ⚡ Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/y-satishreddy/FERN-LANDING-PAGE.git
```

**2. Navigate to the project folder**

```bash
cd FERN-LANDING-PAGE
```

**3. Run the project**

Open `index.html` in your browser or use the Live Server extension in VS Code.
